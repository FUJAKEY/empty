# Bot Menu Mod

Клиентский Fabric-мод для Minecraft 1.21.10, который добавляет кнопку управления ботами в меню паузы. Кнопка располагается справа снизу экрана паузы и открывает экран менеджера ботов с возможностью добавления, удаления и имитации подключения/отключения сохранённых ников.

## Сборка
Перед сборкой нужно восстановить двоичный `gradle-wrapper.jar` из текстовой копии (бинарники не хранятся в репозитории). Для
сборки требуется JDK 21:
```bash
./scripts/restore-wrapper.sh
./gradlew build
```
Готовый JAR появится в `build/libs`.

## Функциональность
- Кнопка "Add Bot to Server" в меню паузы открывает экран управления.
- Экран позволяет добавлять новые ники ботов, удалять выбранные и помечать их как подключённых/отключённых.
- Состояние списка сохраняется в `config/botmenu.json` в директории игры.
- Подключение реализовано как эмуляция состояния для наглядности без запуска отдельного клиента.
